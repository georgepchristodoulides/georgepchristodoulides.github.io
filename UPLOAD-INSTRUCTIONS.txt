GITHUB PAGES — ΕΚΔΟΣΗ ΧΩΡΙΣ ΦΑΚΕΛΟΥΣ

Αυτό το πακέτο περιέχει μόνο αρχεία. Δεν χρειάζεται να ανεβάσετε κανέναν φάκελο.

1. Αποσυμπιέστε το ZIP στον υπολογιστή σας.
2. Ανοίξτε το repository georgepchristodoulides.github.io στο GitHub.
3. Πατήστε Add file → Upload files → choose your files.
4. Μέσα στον αποσυμπιεσμένο φάκελο, επιλέξτε ΟΛΑ τα αρχεία μαζί (Ctrl+A) και πατήστε Open.
5. Βεβαιωθείτε ότι εμφανίζονται τα index.html, styles.css και τα έξι αρχεία cover-....jpg.
6. Πατήστε Commit changes.
7. Περιμένετε 1-3 λεπτά, ανοίξτε https://georgepchristodoulides.github.io/ και πατήστε Ctrl+F5.

Τα αρχεία με το ίδιο όνομα θα αντικαταστήσουν την παλιά έκδοση. Δεν χρειάζεται να διαγράψετε το README ή άλλα άσχετα αρχεία.
